# Web Development Reference

A collection of personal notes, configuration examples, and workflows.

These guides cover CSS preprocessing, asset bundling, CSS processing, and build automation.

## Contents

### Stylesheets

- [LESS](less/less.md) — Compile LESS stylesheets into CSS.
- [PostCSS and Autoprefixer](less/postcss.md) — Process CSS and automatically add vendor prefixes.

### Build Tools

- [Webpack](less/webpack.md) — Bundle JavaScript, stylesheets, and other front-end assets.
- [Gulp](less/gulp.md) — Automate stylesheet compilation, minification, file copying, and other build tasks.

## Purpose

These notes serve as a personal reference for setting up and configuring front-end development tools.

Examples may need adjustments depending on the project structure, installed package versions, and build requirements.
