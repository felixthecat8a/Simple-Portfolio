My Projects

Felix8A

  The Felix8A library is a lightweight Arduino library designed for simple input and output device control. It combines LED, button, and timer utilities into a single, easy-to-use package.

WS2812 Light Control Box

  I used the library to make a sketch that updates the colors of a WS2812 LED string, similar to Christmas tree lights, using a push button. I used Tinkercad and a 3D printer to design and fabricate a control box that houses an Arduino Nano, a momentary push button, a latching button, and a 9V battery.


Equipment: Arduino Nano Every, Arduino Nano Terminal Adapter, Apiele® Latching and Non-latching Pushbuttons & 3D Printer

Tech: PlatformIO, C++, Arduino & Tinkercad

FelixSense

  The FelixSense library is a lightweight Arduino library for analog sensors such as photoresistors, thermistors, and potentiometers. It provides smoothing, normalization, mapped outputs, calculations, and easy sensor-specific classes.

RGB Thermometer

  I used the library to build a digital thermometer that reads temperature from a thermistor-resistor sensor circuit and display it on an 18-Pin RGB LCD module. The LCD module's RGB pins are used to visually represent temperature through color, while a photoresistor-resistor sensor circuit adjusts display brightness based on ambient light levels.

  I used Timkercad to design and print a platform to mount an Arduino UNO R3 and breadboard.

Equipment: Arduino UNO R3, 18-pin RGB LCD Module, breadboard & 3D Printer

Tech: PlatformIO, C++, Arduino & Tinkercad

Arduino RESTful Weather Server

Equipment: Arduino Nano RP2040 Connect, AHT20 sensor

Libraries: WiFiNINA, ArduinoJson

Tech: Arduino IDE, JavaScript, HTML, CSS
