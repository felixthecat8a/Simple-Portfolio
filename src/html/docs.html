Introduction

The Felix8A library is a lightweight Arduino toolkit for working with common components such as LEDs, RGB lighting, buttons, timing utilities, and color helpers.

Getting Started

Follow these quick installation steps to add the Felix8A library to your project.

Install via ZIP file

  1. Download the .zip file of the latest release.
  2. In the Arduino IDE, go to "Sketch > Include Library > Add .ZIP Library...." and select the downloaded .zip file.

Updating the Library

  1. Go to Documents > Arduino > libraries > Felix8A and delete the existing Felix8A folder from your libraries directory.
  2. Follow the installation steps above to install the latest version.

Add to PlatformIO Project

platformio.ini

  lib_deps =
    https://github.com/felixthecat8a/Felix8A.git

Felix8A::LED Class

The Felix8A::LED class provides a simple interface for controlling a single digital LED. It supports basic operations such as turning the LED on/off, toggling state, and handling active-low configurations.

Constructor


    LED(uint8_t pin, bool activeLow = false);
Parameter Type Description
pin uint8_t GPIO pin connected to the LED
activeLow bool Set to true if the LED is active-low (default: false)
Tip: Use activeLow = true for boards where the LED turns on when the pin is LOW.
example.ino

    #include <Felix8A.h>
    #define LED_PIN 5
    Felix8A::LED led(LED_PIN);

Methods

void begin()

Initializes the LED pin and prepares it for output.

example.ino

    void setup() {
      led.begin();
    }
void on()

Turns the LED on.

example.ino

    void setup() {
      led.begin();
      led.on();
    }
void off()

Turns the LED off.

example.ino

    void loop() {
      led.on();
      delay(1000);

      led.off();
      delay(1000);
    }
void toggle()

Toggles the LED between ON and OFF states.

example.ino

    void loop() {
      led.toggle();
      delay(1000);
    }
bool isOn()

Returns the current state of the LED.

Returns
true The LED is currently ON
false The LED is currently OFF
Note: This reflects the stored state, not a physical read from the pin.
example.ino

    void loop() {
      if (led.isOn()) {
        led.off();
      } else {
        led.on();
      }
      delay(1000);
    }
void setPin(uint8_t pin)

Changes the GPIO pin used by the LED.

Parameters
pin New GPIO pin number
uint8_t getPin()

Returns the GPIO pin currently assigned to the LED.

Returns
uint8_t The GPIO pin number used by the LED
Note: This value reflects the current configuration and may change if setPin() is called.
void setActiveLow(bool enable)

Sets whether the LED is active-low. When enabled, the LED turns on when the pin is LOW.

Parameters
enable Set true to enable active-low
bool isActiveLow()

Returns whether the LED is configured as active-low.

Returns
true The LED turns on when the pin is LOW
false The LED operates in standard active-high mode
Note: This is a configuration setting. Use isOn() to check the current LED state.

Felix8A::PWM Class

The Felix8A::PWM class provides brightness control for LEDs using Pulse Width Modulation (PWM). It supports both basic Arduino PWM and optimized ESP32 hardware PWM.

Note: On ESP32, this class uses hardware LEDC channels for efficient PWM output.

Constructor


    PWM(uint8_t pin, bool activeLow = false, LED_t type = BASIC_LED, int8_t channel = -1);
Parameter Type Description
pin uint8_t GPIO pin connected to the LED
activeLow bool Set to true if the LED is active-low
type LED_t Type of PWM implementation (BASIC_LED or ESP32_LED)
channel int8_t Optional ESP32 LEDC channel (-1 for auto allocation)
Note: Select pins with the ~ symbol.
example.ino

    #include <Felix8A.h>
    #define PWM_PIN 6
    Felix8A::PWM led(PWM_PIN);

Methods

void begin()

Initializes the PWM output for the configured pin.

example.ino

    void setup() {
      pwn.begin();
    }
Note: On ESP32, this configures a hardware LEDC channel.
void setPWM(uint8_t level)

Sets the PWM level of the LED.

Parameters
level Brightness value (0-255)
Note: This method automatically handles active-low inversion.
void setBrightness(uint8_t brightness)

Alias for setPWM().

void setGlow(uint8_t glow)

Alias for setPWM().

void on()

Sets brightness to maximum (fully on).

void off()

Turns the LED off (brightness = 0).

void toggle()

Toggles between fully ON and OFF states.

Behavior: toggle() switches between OFF and maximum brightness, not the previous brightness level.

Platform Notes

  • Arduino: Uses standard PWM output via analogWrite()
  • ESP32: Uses hardware LEDC channels

Felix8A::RGB Class

The Felix8A::RGB class provides advanced control over RGB LEDs, supporting multiple color formats including RGB, HEX, HSV, and CMYK. It supports setting colors via RGB values, hexadecimal codes, and brightness control.

Note: Each color channel (Red, Green, Blue) uses PWM for smooth color mixing.
Tip: Use setHSV() for smooth color transitions and animations.

Constructor


    RGB(uint8_t rPin, uint8_t gPin, uint8_t bPin, bool commonAnode = true, LED_t type = BASIC_LED, int8_t rCh = -1, int8_t gCh = -1, int8_t bCh = -1);
Parameter Type Description
rPin uint8_t Red channel pin
gPin uint8_t Green channel pin
bPin uint8_t Blue channel pin
activeLow bool Set to true if the LED is common-anode (active-low)
example.ino

    #include <Felix8A.h>
    #define RED_PIN 9
    #define GREEN_PIN 10
    #define BLUE_PIN 11
    Felix8A::RGB rgb(RED_PIN, GREEN_PIN, BLUE_PIN);
Note: Select pins with the ~ symbol.

Methods

void begin()

Initializes all RGB pins for PWM output.

example.ino

    void setup() {
      rgb.begin();
    }
setRGB(...)

Sets the LED color using RGB values.


    void setRGB(uint8_t r, uint8_t g, uint8_t b);
    void setRGB(uint32_t hex);
    void setRGB(const uint8_t rgb[3]);
    void setRGB(const RGB_Color& c);
Parameter
rRed value (0-255)
gGreen value (0-255)
bBlue value (0-255)
hex Hexadecimal color value such as 0xFF0000 for Red
Note: Values are automatically adjusted for brightness and gamma correction if enabled.
void setHex(uint32_t hex)

Sets the LED color using a hexadecimal value.

Parameters
hex Hexadecimal color value such as 0x00FF00 for Green
void setHSV(int hue, float sat = 1.0, float val = 1.0)

Sets the LED color using HSV (Hue, Saturation, Value).

Parameters
hue0-360 degrees
sat0.0-1.0
val0.0-1.0
Best For: Animations, color cycling, smooth transitions
void setBrightness(uint8_t brightness)

Adjusts overall brightness without changing color.

Parameters
brightness Brightness value (0-255)
void setGammaCorrection(bool enabled)

Enables or disables gamma correction for more natural brightness perception.

Why it matters: Human eyes perceive brightness non-linearly.
Color Presets

Quickly set common colors:

void off()

Turns off all RGB channels.

void getRGB(uint8_t &r, uint8_t &g, uint8_t &b)

Retrieves the current RGB color values.

Parameter
r Reference to store red value
g Reference to store green value
b Reference to store blue value
uint32_t getHex()

Returns the current color as a hexadecimal value such as 0x0000FF for Blue.

Felix8A::Button Class

The Felix8A::Button class provides debounced button input handling with built-in support for press, release, click, multi-click, and hold events.

Tip: Call update() in your main loop to process button events.

Constructor


    Button(uint8_t pin, bool activeLow = true, uint16_t debounceTime = 50);
Parameter Type Description
pin uint8_t Button pin
activeLow bool
debounceTime uint16_t
example.ino

    #include <Felix8A.h>
    #define BUTTON_PIN 2
    Felix8A::Button button(BUTTON_PIN);

Methods

void begin()

Initializes the button input pin and internal state.

example.ino

    void setup() {
      button.begin();
    }
void update()

Updates the button state. This method must be called repeatedly (typically inside loop()) to detect events.

example.ino

    void loop() {
      button.update();
    }
bool isDown()

Returns true if the button is currently pressed.

bool isHeld()

Returns true if the button is currently being held (after the hold threshold is reached).

Event poll()

Returns the most recent button event and clears it.

Possible values:

  • None
  • Press
  • Release
  • Click
  • DoubleClick
  • TripleClick
  • Hold
bool wasPressed()

Returns true once when the button is pressed.

example.ino

    void loop() {
      button.update();

      if (button.wasPressed()) {
        Serial.println("Pressed!");
      }

    }
bool wasReleased()

Returns true once when the button is released.

example.ino

    void loop() {
      button.update();

      if (button.wasReleased()) {
        Serial.println("Released!");
      }

    }
bool wasClicked()

Returns true when a single click is detected.

example.ino

    void loop() {
      button.update();

      if (button.wasClicked()) {
        Serial.println("Click!");
      }

    }
bool wasDoubleClicked()

Returns true when a double-click is detected.

example.ino

    void loop() {
      button.update();

      if (button.wasDoubleClicked()) {
        Serial.println("Double Click!");
      }

    }
bool wasTripleClicked()

Returns true when a triple-click is detected.

example.ino

    void loop() {
      button.update();

      if (button.wasTripleClicked()) {
        Serial.println("Triple Click!");
      }

    }
bool wasHeld()

Returns true once when the button enters the hold state.

example.ino

    void loop() {
      button.update();

      if (button.wasHeld()) {
        Serial.println("Held!");
      }

    }
void setHoldTime(uint16_t ms)

Sets the duration (in milliseconds) required to trigger a hold event.

example.ino

    void setup() {
      button.begin();
      button.setHoldTime(900);
      button.setMultiClickTime(250);
    }
void setMultiClickTime(uint16_t ms)

Sets the maximum time interval between clicks for multi-click detection.

example.ino

    void setup() {
      button.begin();
      button.setHoldTime(900);
      button.setMultiClickTime(250);
    }

Felix8A::Color32 Utility Class

The Felix8A::Color32 class provides lightweight utilities for working with 24-bit RGB colors packed into a single uint32_t.

Format: Colors are stored as 0xRRGGBB.

Methods

uint32_t hex(uint8_t r, uint8_t g, uint8_t b)

Creates a packed 24-bit color from RGB values.


    uint32_t color = Color32::hex(255, 0, 0); // Red
uint32_t rgb(uint8_t r, uint8_t g, uint8_t b)

Alias for hex().

uint32_t fromHex(uint32_t c)

Ensures a value is treated as a 24-bit color by masking out extra bits.

uint8_t red(uint32_t c)

Extracts the red channel (0-255).

uint8_t green(uint32_t c)

Extracts the green channel (0-255).

uint8_t blue(uint32_t c)

Extracts the blue channel (0-255).

uint32_t scale(uint32_t color, uint8_t brightness)

Scales a color's brightness while preserving its hue.

  • brightness = 0 → off
  • brightness = 255 → full brightness

    auto dimRed = Color32::scale(Color32::RED, 128);
uint32_t blend(uint32_t a, uint32_t b, uint8_t t)

Linearly interpolates between two colors.

  • t = 0 → color A
  • t = 255 → color B

    auto purple = Color32::blend(Color32::RED, Color32::BLUE, 128);

Felix8A::Palette Class

The Felix8A::Palette class represents a collection of colors that can be indexed or smoothly interpolated to create gradients.

Tip: Use lerp() to generate smooth color transitions across a palette.

Constructors


    Palette(const uint32_t* colors, uint8_t size);

    template <size_t N>
    Palette(const uint32_t (&colors)[N]);
Parameter Type Description
colors const uint32_t* Pointer to an array of 24-bit colors (0xRRGGBB) used by the palette.
size uint8_t Number of colors in the palette. Used for indexing and interpolation.
Note: The palette does not copy the array; it stores a reference. Ensure the color array remains valid.
example.ino

    constexpr uint32_t colors[] = {
      Color32::RED,
      Color32::GREEN,
      Color32::BLUE
    };

    Palette palette(colors);

Methods

uint8_t size()

Returns the number of colors in the palette.

uint8_t count()

Alias for size().

const uint32_t* data()

Returns a pointer to the underlying color array.

uint32_t operator[](uint8_t i)

Returns the color at index i. The index wraps automatically, allowing seamless looping through the palette. 


    palette[0];    // First color
    palette[10];   // Wraps if size < 10
uint32_t reversed(uint8_t i)

Returns colors in reverse order, with automatic wrapping.

uint32_t lerp(uint8_t t)

Interpolates smoothly across the palette.

  • t = 0 → first color
  • t = 255 → last color

palette.lerp(128) would be the midpoint gradient.

example.ino

    void loop() {
      static uint8_t t = 0;
      rgb.setHex(palette.lerp(t));
      t++;
    }
uint32_t blend(uint32_t c1, uint32_t c2, uint8_t t)

Blends two colors together using linear interpolation.

Parameter Type Description
c1 uint32_t First color (start of the blend).
c2 uint32_t Second color (end of the blend).
t uint8_t Interpolation factor (0-255). 0 returns c1, 255 returns c2, values in between produce a smooth blend.
uint8_t lerp8(uint8_t a, uint8_t b, uint8_t t)

Performs an 8-bit linear interpolation between two values. Commonly used for smooth transitions in color calculations.

Parameter Type Description
a uint8_t Starting value.
b uint8_t Ending value.
t uint8_t Interpolation factor (0-255). 0 returns a, 255 returns b, values in between produce a linear interpolation.

Felix8A::Time Utility

The Felix8A::Time class provides lightweight, non-blocking timing utilities built on top of millis().

Tip: Use these methods instead of delay() for responsive, non-blocking code.

Methods

bool every(unsigned long interval, unsigned long& last)

Triggers repeatedly at a fixed interval. Automatically compensates for drift to maintain consistent timing.

Parameter Type Description
interval unsigned long Interval in milliseconds.
last unsigned long& Timestamp of the last trigger (updated automatically).
example.ino

    unsigned long last = 0;

    void loop() {
      if (Time::every(1000, last)) {
        // Runs every 1 second
      }
    }
bool after(unsigned long interval, unsigned long start)

Returns true once the specified time has elapsed since start.

Parameter Type Description
interval unsigned long Duration in milliseconds.
start unsigned long Start timestamp.
void reset(unsigned long& timestamp)

Sets the given timestamp to the current time (millis()).

Parameter Type Description
timestamp unsigned long& Variable to store the current time.
bool once(unsigned long interval, unsigned long& start)

Triggers only once after the specified interval. Automatically resets itselfafter firing.

Parameter Type Description
interval unsigned long Delay in milliseconds.
start unsigned long& Start timestamp. Must be non-zero to be active. Reset to 0 after triggering.
example.ino

    unsigned long timer = millis(); // arm

    void loop() {
      if (Time::once(2000, timer)) {
        // Runs once after 2 seconds
      }
    }

Common Patterns

Blink Without delay()

example.ino

    unsigned long t = 0;

    void loop() {
      if (Time::every(500, t)) {
        led.toggle();
      }
    }

One-Shot Timer

example.ino

    unsigned long t = millis();

    void loop() {
      if (Time::once(3000, t)) {
        // fires once after 3s
      }
    }
