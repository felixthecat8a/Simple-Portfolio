My Projects

Felix8A Arduino Library

  Felix8A is a lightweight Arduino library designed for simple input and output device control. It combines LED, button, and sensor utilities into a single, easy-to-use package.

  WS2812 Light Control Box: I used the library to make a sketch that updates the colors of a WS2812 LED string, similar to Christmas tree lights, using a push button. I used Tinkercad and a 3D printer to design and fabricate a control box that houses an Arduino Nano, a momentary push button, a latching button, and a 9V battery.

  Quiz Show Button System: I used the Felix8A library to build a four-player quiz show button system using an Arduino. Each player has a dedicated push button and indicator LED. When a player presses their button, the corresponding LED illuminates, and the system locks out additional player inputs until the host presses the reset button to begin the next round. A separate indicator LED signals when the system is ready for another round.

  RGB Thermometer: The Felix8A library was also used to build a digital thermometer that reads temperature from a thermistor and display it on an 18-Pin RGB LCD. The LCD's RGB pins are used to visually represent temperature through color, while a photoresistor adjusts display brightness based on ambient light levels.

Technology: Arduino, PlatformIO, C++, & Tinkercad
