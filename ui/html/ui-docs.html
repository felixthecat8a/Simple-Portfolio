Introduction

The Felix8A library is a lightweight Arduino toolkit for working with common components such as LEDs, RGB lighting, buttons, timing utilities, and color helpers.

Getting Started

Follow these quick installation steps to add the Felix8A library to your project.

Install via ZIP file

  1. Download the .zip file of the latest release.
  2. In the Arduino IDE, go to "Sketch > Include Library > Add .ZIP Library...." and select the downloaded .zip file.

Updating the Library

  1. Go to Documents > Arduino > libraries > Felix8A and delete the existing Felix8A folder from your libraries directory.
  2. Follow the installation steps above to install the latest version.

Add to PlatformIO Project

platformio.ini

  lib_deps =
    https://github.com/felixthecat8a/Felix8A.git

Felix8A::LED Class

Constructor


    LED(uint8_t pin, bool activeLow = false);
Parameters
NameTypeDescription
pinuint8_tGPIO pin connected to the LED
activeLowboolSet to true if the LED is active-low (default: false)
Tip: Use activeLow = true for boards where the LED turns on when the pin is LOW.
example.ino

    #include <Felix8A.h>
    #define LED_PIN 5
    Felix8A::LED led(LED_PIN);

Methods

void begin()

Initializes the LED pin and prepares it for output.

example.ino

    void setup() {
      led.begin();
    }
void on()

Turns the LED on.

example.ino

    void setup() {
      led.begin();
      led.on();
    }
void off()

Turns the LED off.

example.ino

    void loop() {
      led.on();
      delay(1000);

      led.off();
      delay(1000);
    }
void toggle()

Toggles the LED between ON and OFF states.

example.ino

    void loop() {
      led.toggle();
      delay(1000);
    }
bool isOn()

Returns the current state of the LED.

Returns
ValueDescription
trueThe LED is currently ON
falseThe LED is currently OFF
Note: This reflects the stored state, not a physical read from the pin.
example.ino

    void loop() {
      if (led.isOn()) {
        led.off();
      } else {
        led.on();
      }
      delay(1000);
    }
